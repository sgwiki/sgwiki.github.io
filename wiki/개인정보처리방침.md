# 개인정보 처리방침

SG 위키(<https://sgwiki.github.io/>)는 「개인정보 보호법」 제30조에 따라 다음과 같이
개인정보 처리방침을 수립·공개합니다.

---

## 1. 어디에 적용되나

**위키 문서를 읽는 동안에는 개인정보를 수집하지 않습니다.** 방문자 분석 도구도, 광고도
쓰지 않습니다.

이 방침은 우측 하단의 **아마데우스 대화창**(이하 "챗봇")에만 적용됩니다. 챗봇은 직접 눌러
열고, 동의한 경우에만 동작합니다. 동의하지 않아도 위키의 모든 문서를 그대로 보실 수 있습니다.

> 위키 화면은 웹폰트를 Google Fonts에서 불러오며, 이 과정에서 방문자의 IP가 Google에
> 전달됩니다. 위키는 그 정보를 받지 않습니다.

---

## 2. 무엇을, 왜, 얼마나

| 수집 항목 | 목적 | 보유 기간 |
|---|---|---|
| 대화 내용 (보낸 메시지와 챗봇의 답변) | 이전 대화 잇기 · 챗봇 응답 품질 개선 · 어떤 위키 문서를 쓸지 정하기 | **1년** |
| 무작위 식별 번호 (이름·계정과 연결되지 않음) | 같은 방문자의 대화를 이어 붙이기 | **1년** |
| 접속 IP · 브라우저 정보 · 접속 일시 | 서버 접속 과정에서 자동 기록 | **1년** |

광고·마케팅, 방문자 프로파일링, 제3자 판매에는 **사용하지 않습니다.**

**대화창에 이름·연락처·주민등록번호 등 개인을 알아볼 수 있는 정보를 입력하지 마십시오.**
챗봇은 그런 정보를 필요로 하지 않으며, 입력하시면 대화 기록에 함께 저장됩니다.

**파기.** 보유 기간이 지난 정보는 운영자가 주기적으로 점검하여 복구할 수 없는 방법으로
파기합니다. 파기를 요청하시면 기간이 남아 있어도 지체 없이 파기합니다(6항). 다만 대화에서
얻은 판단을 반영해 고친 챗봇 설정이나 그렇게 작성된 위키 문서는 개인정보에 해당하지 않으므로
파기 대상이 아닙니다.

## 3. 쿠키와 브라우저 저장소

챗봇은 방문자를 다시 알아보기 위해 아래를 사용합니다. **동의하기 전에는 하나도 만들어지지
않으며, 챗봇 서버로 요청도 나가지 않습니다.**

| 이름 | 쓰임 | 보관 |
|---|---|---|
| `webchat_uid` (쿠키) | 방문자 식별 | 1년 |
| `amadeus_vid` | 쿠키를 쓸 수 없을 때의 예비 식별 번호 | 삭제 전까지 |
| `amadeus_poc_session` | 이전 대화를 잇는 핸들 | 삭제 전까지 |
| `amadeus_theme` | 주간/야간 선택 | 삭제 전까지 |
| `amadeus_boot_played` | 접속 연출을 한 번만 보여주기 | 탭을 닫으면 사라짐 |
| `amadeus_consent` · `amadeus_chat_panel` · `__palette` | 동의 여부, 창을 닫아 둔 선택, 주간/야간 | 삭제 전까지 |

마지막 세 가지는 **방문자가 직접 한 선택을 기억하기 위한 것**이고 식별·추적에 쓰지 않습니다.
이것까지 없애면 "거부"를 눌러도 페이지마다 다시 묻게 되므로 동의 없이 사용합니다.

**거부 방법:** 동의 화면에서 **[거부하기]**. 이미 동의하셨다면 대화창 제목줄의 **⏻** 버튼을
누르시면 그 뒤로 수집하지 않습니다. 브라우저 설정에서 쿠키를 차단하거나 사이트 데이터를
삭제하셔도 됩니다.

## 4. 국외 이전

개인정보를 제3자에게 제공하지 않습니다. 다만 **챗봇의 답변은 외부 인공지능 모델 사업자를
통해 생성되며, 이 과정에서 대화 내용이 국외로 이전됩니다.**

| 구분 | 내용 |
|---|---|
| 이전받는 자 | JINGSHENG HENGXING TECHNOLOGY PTE. LTD. (서비스명 Z.ai) · <user_feedback@z.ai> |
| 이전 국가 | **싱가포르** (해당 사업자가 개인정보를 일반적으로 싱가포르에서 처리한다고 공개) |
| 시기 · 방법 | 메시지를 보낼 때마다 암호화 통신(HTTPS)으로 실시간 전송 |
| 이전 항목 | 대화 내용. 답변 생성 시에는 진행 중인 대화를, 위키 문서 작성 지원 시에는 보관 중인 과거 대화를 함께 보냅니다. **식별 번호 · IP · 쿠키는 전송하지 않습니다** |
| 이용 목적 | 질문에 대한 답변 생성 · **위키 문서 작성 지원**(어떤 문서를 쓸지 정하고 설명이 부족한 곳을 찾는 데 사용하며, 대화 내용을 위키 본문에 싣지는 않습니다) |
| 보유 기간 | **보관하지 않음.** 해당 사업자는 API 로 받은 내용을 실시간 처리 후 저장하지 않고 모델 학습에도 쓰지 않는다고 공개 |
| 거부 방법 | 동의 화면에서 **[거부하기]**. 챗봇을 쓰지 않으면 이전할 내용도 없습니다 |

모델 사업자가 바뀌면 이 항목을 갱신하고 동의를 다시 받습니다.

## 5. 안전성 확보 조치

통신 구간을 모두 암호화(HTTPS)하고, 서버에 저장하는 식별 번호는 원본이 아닌 해시(HMAC)로
변환해 사용합니다. 대화 기록에 접근할 수 있는 것은 **운영자 본인과, 위키 문서 작성을 위해
운영자가 실행하는 자동화 도구**로 한정합니다.

만 14세 미만 아동을 대상으로 하지 않으며, 아동이 이용한 사실을 알게 되면 해당 기록을 지체
